# Glossário — Registro de Imóveis

| Termo | Significado |
|-------|-------------|
| **Apresentação** | Entrega do título ao RI para registro/averbação |
| **Prenotação / protocolo** | Anotação no Livro 1 com número de ordem e prioridade |
| **Caducidade do protocolo** | Perda do efeito após 30 dias sem registro nem devolução válida |
| **Matrícula** | Ficha do imóvel no Livro 2 (identidade registral) |
| **Registro** | Ato que transmite propriedade ou constitui ônus real |
| **Averbação** | Ato que altera matrícula ou qualificação das partes |
| **Qualificação registral** | Exame jurídico do título pelo oficial |
| **Nota de devolução** | Lista formal de exigências para registrar |
| **Suscitação de dúvida** | Questionamento da exigência perante o juiz corregedor |
| **Continuidade** | Encadeamento com proprietário/ônus já registrados |
| **Territorialidade** | Competência do RI da circunscrição do imóvel |
| **Indicador real** | Busca por endereço/denominação → matrícula |
| **Indicador pessoal** | Busca por nome/CPF → matrículas vinculadas |
| **Transcrição** | Sistema legado anterior à matrícula (pré-1976) |
| **Inteiro teor** | Certidão com histórico completo da matrícula |
| **DOI** | Declaração de Operações Imobiliárias à Receita Federal |
| **ONR** | Operador Nacional do SREI — coordenação nacional |
| **RI Digital** | Plataforma de serviços eletrônicos do registral imobiliário |
| **CNIB** | Central de indisponibilidade de bens (integração RI) |
