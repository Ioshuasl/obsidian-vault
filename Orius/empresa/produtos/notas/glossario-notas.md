# Glossário — Tabelionato de Notas

| Termo | Significado |
|-------|-------------|
| **Extraprotocolar** | Ato de balcão, em geral sem registro integral em livro |
| **Protocolar / notarial** | Ato registrado permanentemente em livro oficial |
| **Ficha / cartão de assinatura** | Cadastro da assinatura da pessoa no cartório |
| **Reconhecimento por semelhança** | Comparação com assinatura arquivada |
| **Reconhecimento por autenticidade** | Assinatura feita perante o escrevente |
| **Abono** | Terceiro conhecido atesta identidade de quem não tem ficha |
| **Autenticação** | Cópia fiel ao original apresentado |
| **Escritura pública** | Ato solene de negócio jurídico relevante |
| **Outorgante / outorgado** | Quem dá / quem recebe poderes ou direitos |
| **Traslado** | Primeira cópia oficial na lavratura |
| **Certidão** | Cópia oficial posterior do que está no livro |
| **Sinal público** | Autenticação da assinatura de outro tabelião |
| **Páginas acrescidas** | Folhas extras em ato longo |
| **DOI** | Declaração de operações imobiliárias à Receita |
| **CENSEC** | Central nacional de informação notarial compartilhada |
| **CCN** | Cadastro único de clientes do notariado |
| **e-Notariado** | Plataforma nacional de atos e assinaturas eletrônicos |
