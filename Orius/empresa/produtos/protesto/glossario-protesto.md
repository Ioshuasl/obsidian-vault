# Glossário — protesto de títulos

| Termo | Significado |
|-------|-------------|
| **Apresentante** | Quem leva o título ao cartório (credor, banco, factoring, procurador). |
| **Apresentação** | Ato de entregar o título para iniciar o procedimento. |
| **Apontamento** | Registro da entrada do título no cartório (protocolo, número, data/hora). |
| **Sacado / devedor** | Quem deve pagar o título. |
| **Intimação** | Comunicação oficial ao devedor para pagar no prazo legal. |
| **Tríduo** | Prazo de **3 dias úteis** após a intimação para o devedor resolver. |
| **Lavrar / protestar o título** | Registrar oficialmente a inadimplência após o tríduo. |
| **Protesto lavrado** | Título com protesto registrado e público. |
| **Elisão** | Pagamento no prazo, evitando o protesto; título elidido. |
| **Desistência / retirada** | Apresentante retira o título antes do protesto. |
| **Sustação** | Suspensão do protesto por ordem judicial. |
| **Cancelamento** | Baixa do protesto após quitação e documentação adequada. |
| **Distribuição** | Encaminhamento do título ao cartório competente na comarca. |
| **Remessa (CRA)** | Arquivo eletrônico de lote enviado pelo apresentante. |
| **Confirmação (CRA)** | Arquivo que confirma recebimento da remessa. |
| **Retorno (CRA)** | Arquivo com resultado por título (protestado, pago, etc.). |
| **Importação** | Processamento interno do arquivo de remessa no sistema do cartório. |

## Status comuns em retorno CRA (por título)

| Status | Significado resumido |
|--------|----------------------|
| Protocolizado | Entrada registrada no cartório |
| Intimado | Devedor intimado |
| Pago (Elidido) | Quitado no tríduo — sem protesto |
| Protestado | Protesto lavrado |
| Sustado | Suspenso por judicial |
| Desistido | Apresentante desistiu |
| Cancelado | Protesto cancelado após quitação |
| Rejeitado | Título não aceito (irregularidade) |
