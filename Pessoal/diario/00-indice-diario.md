# Diário — notas diárias

Resumo do dia, checklist de rotina (trabalho, faculdade, academia) e espaço para reflexão rápida.

## Como usar

1. **Abrir nota de hoje:** ícone de calendário na barra lateral (plugin **Daily notes**) ou atalho configurado no Obsidian.
2. As notas são criadas em `Pessoal/diario/AAAA/MM/DD.md` (formato já configurado no cofre).
3. Se a nota vier vazia, confira em **Configurações → Daily notes** se o template aponta para [[Pessoal/diario/_template-nota-diaria]].
